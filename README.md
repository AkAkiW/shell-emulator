# Shell Emulator

Учебный эмулятор командной оболочки UNIX-подобной операционной системы.

Приложение реализовано на Java 21 с использованием Swing и поддерживает интерактивный режим работы, параметры командной строки и выполнение стартового скрипта.

## Требования

- Java 21
- Maven

## Сборка

Для сборки проекта из корневого каталога:

    mvn compile

## Запуск

Для запуска эмулятора используется скрипт `run.sh`.

    ./run.sh <путь_к_VFS> <путь_к_стартовому_скрипту>

Например:

    ./run.sh ./vfs ./vfs/test-script.txt

Эмулятор поддерживает два параметра командной строки:

1. Путь к физическому расположению VFS.
2. Путь к стартовому скрипту.

При запуске параметры выводятся в консоль:

    Количество аргументов: 2
    VFS: /home/user/shell-emulator/vfs
    Стартовый скрипт: /home/user/shell-emulator/vfs/test-script.txt

Путь к VFS на текущем этапе принимается и отображается как параметр конфигурации. Команды `ls` и `cd` пока являются заглушками и не выполняют операции с VFS.

## Графический интерфейс

После запуска открывается графическое окно эмулятора.

Заголовок окна формируется на основе имени пользователя и имени компьютера текущей операционной системы:

    Эмулятор - [username@hostname]

В окне отображаются результаты выполнения стартового скрипта и доступно выполнение команд в интерактивном режиме.

## Стартовый скрипт

Стартовый скрипт представляет собой текстовый файл, содержащий команды эмулятора по одной команде на строку.

Команды выполняются последовательно.

Например:

    ls
    cb /home
    ls "my folder"
    ls "не закрыта
    cd /home

При выполнении скрипта на экран выводятся как введённые команды, так и результаты их выполнения:

    > ls
    ls
    Аргументы: []

    > cb /home
    Неизвестная команда: cb

    > ls "my folder"
    ls
    Аргументы: [my folder]

    > ls "не закрыта
    Ошибка: Незакрытая кавычка

    > cd /home
    cd
    Аргументы: [/home]

Ошибочные строки не останавливают выполнение скрипта. После обработки ошибки выполнение продолжается со следующей строкой.

## Поддерживаемые команды

### `ls`

Заглушка команды `ls`.

Выводит имя команды и переданные аргументы.

Пример:

    ls "my file.txt"

Результат:

    ls
    Аргументы: [my file.txt]

### `cd`

Заглушка команды `cd`.

Выводит имя команды и переданные аргументы.

Пример:

    cd "my folder"

Результат:

    cd
    Аргументы: [my folder]

### `exit`

Завершает работу эмулятора.

## Парсер команд

Эмулятор поддерживает аргументы в одинарных и двойных кавычках.

Например:

    ls "my file.txt"

В данном случае `my file.txt` воспринимается как один аргумент.

Незакрытая кавычка считается ошибкой:

    ls "my file.txt

Результат:

    Ошибка: Незакрытая кавычка

## Тестовые скрипты операционной системы

В каталоге `scripts/` находятся скрипты реальной операционной системы, которые запускают эмулятор и передают ему параметры командной строки.

    scripts/
    ├── test-default.sh
    ├── test-alt-script.sh
    └── test-alt-vfs.sh

### `test-default.sh`

Использует стандартный VFS и стандартный стартовый скрипт:

    VFS: vfs
    Стартовый скрипт: vfs/test-script.txt

Запуск:

    cd scripts
    ./test-default.sh

### `test-alt-script.sh`

Использует стандартный VFS и альтернативный стартовый скрипт:

    VFS: vfs
    Стартовый скрипт: vfs/test-alt-script.txt

Запуск:

    ./test-alt-script.sh

### `test-alt-vfs.sh`

Использует альтернативный физический VFS и стандартный стартовый скрипт:

    VFS: vfs/alt-vfs
    Стартовый скрипт: vfs/test-script.txt

Запуск:

    ./test-alt-vfs.sh

Таким образом, тестовые скрипты демонстрируют передачу обоих поддерживаемых параметров командной строки и изменение каждого из них.
