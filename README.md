# Shell Emulator

Учебный эмулятор командной оболочки, разработанный на Java с использованием Swing.

## Требования

* Java 21
* Maven

## Запуск

Сборка проекта:

```bash
mvn compile
```

Запуск приложения:

```bash
mvn exec:java -Dexec.mainClass="shell.emulator.Main"
```

## Поддерживаемые команды

### `ls`

Заглушка команды `ls`. Выводит название команды и переданные аргументы.

Пример:

```text
ls "my file.txt"
```

### `cd`

Заглушка команды `cd`. Выводит название команды и переданные аргументы.

Пример:

```text
cd "my folder"
```

### `exit`

Завершает работу эмулятора.

## Обработка аргументов

Эмулятор поддерживает аргументы в одинарных и двойных кавычках.

Например:

```text
ls "my file.txt"
```

`my file.txt` воспринимается как один аргумент.

При наличии незакрытой кавычки выводится сообщение об ошибке, после чего эмулятор продолжает работу.

## Структура проекта

Основной исходный код находится в:

```text
src/main/java/shell.emulator/
```

Тестовые и вспомогательные материалы находятся в:

```text
tests/
```
